# content/ — Обучающий контент

Образовательные тексты для каждого поля. Здесь хранится **только текст**, отдельно от игровой механики (которая в `data/`).

## Структура

```
content/
├── ru/
│   └── properties/
│       ├── letterly.md
│       ├── inboxpro.md
│       └── ...
└── en/
    └── properties/
        └── ...
```

## Зачем отдельно от data/

1. **Локализация** — переводы не задевают игровые правила
2. **Обновление цифр** — выручка Google меняется, не должно требовать пересборки данных
3. **Вариативность редакций** — национальная и международная редакции могут иметь разный фокус в текстах

## Формат файла

Каждый файл — Markdown с frontmatter:

```markdown
---
property: findster
edition: all  # all | national | international
---

# Findster

**Реальные аналоги:** Bing, DuckDuckGo

Bing — поисковая система Microsoft, №2 в мире после Google
(около 8% рынка). Зарабатывает на контекстной рекламе и интеграции
с MS Office...
```
