## [Unreleased]

### Added
- Сетевая игра без сервера: комната по коду/QR, каждый играет со своего телефона (WebRTC через PeerJS,
  хост авторитетен, переподключение гостей)
- «Домики»: уровни прокачки хостинга показаны на доске стойками и датацентрами; прокачка своего поля из карточки клетки
- Экран партии в стиле мобильной игры: HUD, анимация кубиков, всплывающая карточка клетки,
  большая кнопка хода, шторки для игроков, действий, сделок и журнала
- Изометрический 3D-вид доски с переключателем на плоский
- Печатные материалы `print/`: поле A2 и A4×4, карточки владений, Шанса и Казны;
  генерируются из `data/` через Chromium и выкладываются на сайт в `/print/`
- Бросок кубиков и перемещение по доске: ход, дубли, СТАРТ, БАН, пропуск хода,
  подсказка по клетке; визуальная доска 11×11 с фишками игроков
- Карточки «Иди на …», «БАН» и «Пропусти ход» применяются к игроку автоматически
- MVP веб-приложения `apps/web` (Next.js, static export): доска, карточки полей,
  калькулятор ренты, колоды Шанса/Казны, партия с деньгами, трафиком и консенсусом,
  QR-коды для печати
- Скрипт валидации `data/` (`npm run validate:data`) и CI на его основе
- Workflow деплоя на GitHub Pages
- Обучающие тексты для всех 28 полей в `content/ru/properties/`
- Первоначальная структура репозитория
- Дизайн-документы (концепция, механика, карточки)
- Данные карточек в YAML
- ROADMAP с тремя фазами разработки
