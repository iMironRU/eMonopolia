# apps/api — Бэкенд

**Статус:** не нужен в MVP. Появляется в фазе 2.

## Когда понадобится

Бэкенд нужен только тогда, когда:
- Игроки могут играть удалённо с разных устройств
- Нужно сохранять прогресс партий
- Нужна синхронизация в реальном времени
- Появятся лидерборды и статистика

## Технологии (план)

- Node.js + Fastify или Hono
- WebSocket для real-time синхронизации
- SQLite (для начала) или PostgreSQL
- Деплой — Railway/Fly.io или собственный VPS

## Архитектура (черновик)

```
POST /game/new          — создать партию
GET  /game/:id          — получить состояние
POST /game/:id/move     — сделать ход (требует подтверждение)
POST /game/:id/confirm  — подтвердить чужой ход
WS   /game/:id/stream   — подписка на события партии
```

В MVP (фаза 1) ничего этого не нужно: всё хранится в localStorage браузера.
