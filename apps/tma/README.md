# apps/tma — Telegram Mini App

**Статус:** не начато (фаза 2).

## Что это

Тот же React-код, что и `apps/web`, но запускается внутри Telegram как мини-приложение. Игрок открывает бота → нажимает кнопку → запускается интерфейс прямо в Telegram.

## Преимущества TMA перед обычным веб-приложением

- Не нужно ничего ставить
- Авторизация автоматически (Telegram уже знает кто ты)
- Доступ к TON Wallet (если когда-то решим делать настоящую крипту)
- Уведомления через бота (ход дошёл до тебя!)

## Технологии (план)

- React + Next.js (shared code с apps/web)
- @telegram-apps/sdk-react
- Bot API через python-telegram-bot или Telegraf
