# apps/web — Веб-приложение eMonopolia

**Статус:** MVP (фаза 1). Статический сайт, без бэкенда, состояние партии — в localStorage.

## Что умеет

| Страница | Что делает |
|---|---|
| `/` | Доска: 40 клеток, группы полей, ссылки на карточки |
| `/card/{id}/` | Карточка поля: цена, рента, трафик, обучающий текст из `content/`, калькулятор ренты |
| `/chance/`, `/chest/` | Колоды Шанса и Казны: тасуются, тянутся по одной, применяются к игроку |
| `/game/` | Партия: доска с фишками, бросок кубиков и ход, игроки, деньги и трафик, рента, покупка и прокачка через консенсус, конвертация трафика, сделки, залог, журнал |
| `/qr/` | Печатный лист с 40 QR-кодами — наклеить на клетки, сканировать телефоном |

Сканер QR не встроен: любая камера телефона открывает ссылку с клетки напрямую.

## Как запустить

```bash
cd apps/web
npm install
npm run dev        # http://localhost:3000
npm run build      # статика в apps/web/out
npm run typecheck
```

Данные читаются из `../../data/*.yaml` и `../../content/ru/properties/*.md` на этапе сборки.
Изменил YAML — пересобери.

## Деплой

GitHub Actions (`.github/workflows/web-deploy.yml`) собирает сайт при push в `main` и выкладывает на GitHub Pages.
В настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

Переменные сборки:

- `NEXT_PUBLIC_BASE_PATH` — префикс пути (`/eMonopolia` на Pages, пусто локально)
- `NEXT_PUBLIC_SITE_URL` — абсолютный адрес сайта для QR-кодов

## Модель партии (MVP)

- **Один телефон на стол** — «банк». Все игроки нажимают свои кнопки на нём.
- **Ход**: кнопка «Бросить кубики» двигает фишку текущего игрока по доске, начисляет бонус за СТАРТ,
  даёт повторный бросок за дубль, отправляет в БАН за три дубля или клетку «Под БАН!». Трафик с полей
  начисляется автоматически при первом броске хода. Под броском появляется подсказка по клетке:
  купить, заплатить ренту или налог, тянуть карточку. «Конец хода» передаёт ход следующему.
- **БАН**: выход дублем (3 попытки), после третьей неудачи игрок платит штраф и выходит; можно заплатить до броска.
- **Доска**: сетка 11×11 из `data/board.yaml`, фишки игроков, точка цвета владельца на купленных полях.
  По умолчанию изометрия (CSS 3D: поворот 45° и наклон 55°, фишки стоят вертикально и плавно переезжают),
  кнопка «Плоская / 3D» переключает вид, выбор запоминается в localStorage.
- **Консенсус**: покупка, прокачка, передача поля и конвертация больше 200 $NET создают транзакцию.
  Инициатор голосует «за» автоматически, остальные нажимают «Да»/«Нет». Нужно простое большинство.
- **Трафик**: кнопка «+N трафик» у игрока считает доход со всех его генераторов.
  Конвертеры меняют трафик на $NET по курсу поля; при экосистеме (полная группа генераторов + полная группа конвертеров) курс +25%.
- **Прокачка**: только при полной группе и равномерно (не выше минимального уровня в группе + 1). Уровни: VPS → выделенный сервер → облачный кластер → мультиоблако → собственный датацентр.
- **Рента** считается автоматически с учётом монополии, уровня, количества провайдеров/коммуналок и броска кубиков.
