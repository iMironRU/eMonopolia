# print/ — Печатные материалы

Всё, что нужно физически распечатать. Генерируется из `data/*.yaml` и `content/`, чтобы не расходиться с приложением.

## Что получается

| Файл | Что это | Печать |
|---|---|---|
| `board-a2.pdf` | Игровое поле 400×400 мм + памятка по правилам | A2 портрет, типография |
| `board-a4x4.pdf` | То же поле, нарезанное на 4 листа A4 | Дома, склеить встык |
| `cards-properties.pdf` | 28 карточек владений (22 поля, 4 провайдера, 2 коммуналки) | A4, 9 карточек 65×90 мм на лист |
| `cards-chance.pdf` | 16 карточек Шанса + рубашки | A4, двусторонняя печать |
| `cards-chest.pdf` | 16 карточек Казны + рубашки | A4, двусторонняя печать |

Готовые PDF лежат на сайте: `https://imiron.ru/eMonopolia/print/<файл>` (собираются при каждом деплое).

## Как собрать локально

```bash
cd print
npm install
npx playwright install chromium   # один раз
npm run build                     # → print/out/*.pdf
```

Переменные окружения:

- `SITE_URL` — адрес сайта для QR-кодов (по умолчанию `https://imiron.ru/eMonopolia`)
- `CHROMIUM_PATH` — свой Chromium вместо playwright-овского

`npm run build:html` пишет только HTML в `out/` — удобно открыть в браузере и подправить вёрстку.

## Как устроено

```
print/
├── build.mjs           # оркестратор: HTML → PDF через Chromium, затем нарезка A4
├── lib/
│   ├── data.mjs        # загрузка data/ и content/
│   ├── html.mjs        # общие стили, QR, логотип
│   └── tile.mjs        # нарезка board-a2.pdf на 4 листа A4 (pdf-lib)
└── templates/
    ├── board.mjs       # поле: сетка 11×11, угловые клетки, центр, памятка
    └── cards.mjs       # карточки владений и событий
```

Поле — CSS grid 11×11 из `data/board.yaml`. Угловые клетки в 1,6 раза больше обычных.
Контент боковых клеток повёрнут так, чтобы читаться со своей стороны стола.
На каждой клетке — QR-код на страницу карточки в приложении.

## QR-коды

```
<SITE_URL>/card/{id}/      — поля, провайдеры, коммуналки
<SITE_URL>/chance/         — Шанс
<SITE_URL>/chest/          — Казна
```
