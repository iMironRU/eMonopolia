# print/ — Печатные материалы

Папка для всего, что нужно физически распечатать.

## Содержимое

| Папка | Что внутри |
|---|---|
| `board/` | Игровое поле (40 клеток) — SVG + готовый PDF |
| `cards/` | Карточки полей, провайдеров, коммуналок, Шанса, Казны |
| `rules/` | Правила игры в PDF |

## Подход к генерации

Шаблоны для печати **генерируются из `data/*.yaml`**, чтобы не было расхождений с приложением.

Возможные подходы:
- **HTML + Puppeteer** → PDF (наиболее гибко)
- **SVG + Inkscape CLI** (хорошо для поля)
- **LaTeX** (для красивых правил)

## QR-коды

На каждой клетке физического поля — QR-код, ведущий на страницу карточки в веб-приложении:

```
https://imironru.github.io/eMonopolia/card/{id}
```

QR генерируется автоматически из ID поля.

## Что должно быть готово к концу фазы 1

- [ ] Игровое поле A2 или A1 для печати дома или в типографии
- [ ] Карточки всех 28 владений (формат картонной карточки 65×90мм)
- [ ] Стопка карточек Шанса (16 шт.) и Казны (16 шт.) — необязательно, можно только в приложении
- [ ] Правила в PDF (8-12 страниц)
- [ ] Деньги — печатные купюры (опционально, можно играть с цифровым счётом)
