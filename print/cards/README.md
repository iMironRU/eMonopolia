# print/cards/ — Карточки

Карточки генерируются скриптом из `print/templates/cards.mjs`, см. [print/README.md](../README.md).

## Формат

65×90 мм, 9 штук на лист A4 с тонкими линиями реза.

| Файл | Содержимое |
|---|---|
| `cards-properties.pdf` | 28 карточек владений: цветная шапка группы, таблица ренты по уровням прокачки, цена прокачки, трафик, цена и залог, номер клетки, QR на страницу с обучением, строка «Как в жизни» из `content/` |
| `cards-chance.pdf` | 16 карточек Шанса, затем столько же листов с рубашкой |
| `cards-chest.pdf` | 16 карточек Казны, затем рубашки |

Карточки событий печатаются двусторонне: лицо и рубашка идут одинаковыми листами, чтобы совпасть при перевороте по длинной стороне.

Готовые файлы: `https://imiron.ru/eMonopolia/print/cards-properties.pdf`, `…/cards-chance.pdf`, `…/cards-chest.pdf`.
