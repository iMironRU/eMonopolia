## Формат

Стандарт: 65×90мм (как в классике).
На карточке:
- Имя поля (Findster, VibeNet и т.д.)
- Цена покупки
- Таблица ренты
- Цена прокачки
- Залог
- QR-код для быстрого доступа к подробной странице
