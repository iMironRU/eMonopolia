# print/board/ — Игровое поле

Поле генерируется скриптом из `print/templates/board.mjs`, см. [print/README.md](../README.md).

- `board-a2.pdf` — 400×400 мм на листе A2 (портрет), под полем памятка по правилам.
- `board-a4x4.pdf` — 4 листа A4 для домашней печати. Порядок: 1 верх-лево, 2 верх-право, 3 низ-лево, 4 низ-право. Резать по серой рамке, клеить встык.

Готовые файлы: `https://imiron.ru/eMonopolia/print/board-a2.pdf`, `…/board-a4x4.pdf`.

## Советы по печати

- Плотность бумаги 200–300 г/м², матовая ламинация — поле будет жить дольше.
- Проверьте, что в настройках печати выключено «вписать в страницу»: поле должно быть ровно 400 мм.
- QR-коды рассчитаны на сканирование с 30–50 см.
