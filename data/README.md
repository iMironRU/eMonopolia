# data/ — Единый источник игровых данных

Все игровые данные хранятся здесь как YAML. Это единственный источник истины — приложение, печатные материалы и документация читают отсюда.

## Файлы

| Файл | Содержимое |
|---|---|
| `board.yaml` | Раскладка 40 клеток — что и где стоит |
| `properties.yaml` | 22 покупаемых поля: цена, рента, прокачка, трафик |
| `providers.yaml` | 4 провайдера + таблица ренты |
| `utilities.yaml` | 2 коммуналки + множители ренты |
| `chance.yaml` | 16 карточек Шанса |
| `chest.yaml` | 16 карточек Казны |
| `editions/` | Конфигурация трёх редакций (национальная, международная, смешанная) |

## Принципы

1. **YAML, не JSON** — комментарии, читаемость, проще править руками
2. **ID — kebab-case** строкой (`letterly`, `tubeworld`), нужны для связей между файлами
3. **Имена — на языке игры**, в `name`. Локализация через `content/`
4. **Образовательный текст — НЕ здесь**, а в `content/ru/properties/{id}.md`

## Валидация

CI проверяет:
- На доске ровно 40 клеток
- Все `ref` из `board.yaml` существуют в `properties.yaml` / `providers.yaml` / `utilities.yaml`
- Нет дублей ID
- Цены положительные, рента возрастающая
- Каждая редакция корректно ссылается на существующие поля

## Как добавить новое поле

1. Добавь запись в `properties.yaml` с уникальным `id`
2. Поставь его на свободную позицию в `board.yaml`
3. Создай `content/ru/properties/{id}.md` с обучающим текстом
4. Запусти `npm run validate` (когда будет настроено)
