# Брендинг eMonopolia

## Файлы

| Файл | Назначение |
|---|---|
| `logo-full.svg` | Полный мини-брендбук — главный логотип + 4 варианта. Удобно открывать в Figma для работы. |
| `logo-full.png` | PNG-превью брендбука (для документации и README). |
| `logo-icon.svg` | Только иконка — квадрат 180×180. Для favicon, аватарок, OG-image. |
| `logo-wordmark.svg` | Только текст "eMonopolia" с цветной полоской. Для шапок, документации. |

## Палитра

| Цвет | HEX | Использование |
|---|---|---|
| Тёмно-синий | `#0d1b2a` | Основной — фон иконки, текст |
| Зелёный | `#00b86b` | Акцент — буква "e", богатство/Монополия |
| Красный | `#e63946` | Акцент группы улиц |
| Жёлтый | `#ffc107` | Акцент группы улиц |
| Синий | `#3a86ff` | Акцент группы улиц |
| Фон | `#f8f9fa` | Светлый фон |
| Серый | `#6c757d` | Вторичный текст |

## Типографика

- **Главный шрифт логотипа:** Arial Black / Helvetica Neue Black (font-weight 900)
- **Слоган и подписи:** Helvetica Neue / Arial Regular
- **Слоган разреженный:** `letter-spacing: 6px`, uppercase

## Использование

### ✅ Можно
- Использовать любой вариант в зависимости от контекста
- Менять размер пропорционально
- Использовать на цветных фонах в монохромной версии

### ❌ Нельзя
- Изменять пропорции
- Менять цвета палитры в основных вариантах
- Использовать на пёстром фоне без подложки
- Использовать вариант на тёмном фоне на светлом фоне (и наоборот)
